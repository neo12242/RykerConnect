# Switched-accessory input protection — approved 2026-09-13

1. **Problem:** The corrected REV02 input has no coordinated vehicle-supply protection ahead of its 25V capacitor and 30V diode.
2. **Goals:** Add reverse-polarity blocking, approximately 18V overvoltage disconnect, approximately 1A current limiting and controlled startup; retain the sensor and existing functions. Export a matched, auditable prototype package.
3. **Scope:** New REV03-Protected copy of the main board, input protection circuit, schematic, routing, BOM/CPL/Gerbers, calculation report and prototype acceptance instructions. the project owner confirmed ignition-switched accessory 12V and a one-foot sensor cable, then approved building this change.
4. **Out of scope:** Ordering/payment, changing firmware features, direct battery/always-on operation, automotive certification or a claim of physical testing.
5. **Constraints:** Preserve original and REV02 files. Preserve board outline and mounting holes. Additional bottom-side assembly is permitted as a routine layout choice; enclosure clearance must be checked before fabrication. Use direct 3.3V/100kHz I2C initially.
6. **Approach:** TI TPS26600 reference topology with isolated RTN, programmable voltage thresholds and an asymmetric input TVS pair. Existing USB supply OR-ing remains after the protected accessory output. Use manufacturer/catalog parts with explicit sourcing identities.
7. **Plan:** Validate pin/land patterns and calculations; implement schematic/PCB; run native DRC/ERC/parity and connectivity assertions; regenerate matched exports and document installation tests.
8. **Risks/design envelope:** This is a prototype for a nominal 12V accessory branch. Target normal 9–16V, reverse connection at -16V, overvoltage disconnect during a suppressed load dump up to 35V, and bounded short transients within the selected TVS pulse ratings. Full unsuppressed alternator load dump is NOT established by this circuit. A properly rated upstream branch fuse is required for wiring and TVS faults. Physical surge, thermal, inrush, RF, enclosure and assembly-model checks remain required.
9. **Open questions:** Exact accessory branch fuse/wire rating, mechanical clearance below the board, exact OLED variant and physical electrical validation. These are acceptance checks, not reasons to leave the authorized circuit unimplemented.
